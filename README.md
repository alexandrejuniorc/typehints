# Projeto: Typehints em Python

Este projeto demonstra o uso de type hints (anotações de tipo) em Python, facilitando a leitura, manutenção e validação de código.

## Estrutura
- `typehints1.py`: Arquivo principal com exemplos de type hints.

## Como usar
1. Clone o repositório:
   ```zsh
   git clone <url-do-repositorio>
   ```
2. Instale dependências opcionais para análise de tipos:
   ```zsh
   pip install pylint mypy
   ```
3. Execute o arquivo principal:
   ```zsh
   python typehints1.py
   ```
4. (Opcional) Verifique os tipos com o mypy:
   ```zsh
   mypy typehints1.py
   ```

## Referências
- [PEP 484 – Type hints](https://peps.python.org/pep-0484/)
- [Documentação oficial Python: Type Hints](https://docs.python.org/3/library/typing.html)
